# 电商多模板实现与验收

2026-11-12，StitchPress 0.1.0.dev10。对应设计22及一期 R1-COM01–04；AI模板设计、生图、背景编辑和文案仍是二期。本次没有调用图像供应商。

## 已实现

- 四套独立版式：简约画廊、温暖家居、东方雅韵、清晰商品。每套覆盖7张详情及5个800方图槽位；不同模板的作品区、题头、规格与对比排布、留白及装饰分别定义。
- 「商品图片 → 选择模板」提供当前作品的模板卡片与12页真实预览。选中页放大，进入「编辑当前页面」定位场景或内容设置；输出尺寸和五方图内容另有设置页。
- 明确选择是否保留场景/相框/自选背景、是否重置文案。尺寸、DPI、展示来源、方图内容始终保持；默认保留手写文案，未改过的默认文案随模板切换。
- 模板选择器取消不修改作品；「使用此模板」仅暂存本页；「应用更改」写入当前作品，保存作品才落盘。「撤销模板切换」恢复切换前的本页设置，已经应用过时仍须应用撤销后的设置。
- 「我的预设」保存、导入、导出 `.stitchtemplate`，可选择独立商品字体。同名本地预设另存版本，不覆盖旧文件；快照携带引用的背景及字体。默认不携带当前原图、针格、客户信息，文案中的当前名称/货号转换成占位符。
- 新建示例作品默认简约画廊；缺少模板字段的旧作品维持经典布局，不自动迁移。
- 模板是经过字段、布局边界和完整性校验的数据，不执行脚本。模板快照、配置、资源及字体版本进入预览/导出校验；迟到结果不能覆盖新参数。独立进程可取消，缺原图/文字溢出按页面显示原因。
- 商品模板自带可再分发的 Noto Sans CJK 中文字体，不受生产字体选择影响。经典版保持原有字体规则。预设携带字体后可在另一台安装本软件的电脑离线使用。

## 三轮审查

本机证据在 `reports/local/commerce-templates/`；客户用例保留于本机，不提交仓库。

| 轮次 | 实查范围 | 问题与修正 |
|---|---|---|
| 1 | 四套48页全套缩略图、蓝绣球原图与针格 | 规格小数过长，统一为最多两位；横向输出按宽高共同约束字号，保留越界拒绝；检查主体比例、页脚与方图 |
| 2 | 原生模板选择器、实际模板卡片、全套页面、规格放大 | Retina预览低分辨率缩放导致文字发糊，按设备像素比绘制；补独立列表名称；取消按钮中文化；移除重复的实际预览按钮 |
| 3 | 高清预览、切换/取消/撤销、字体与预设 | 生产字体不应改变商品默认中文排版，改为独立字体并嵌入个人预设；字体版本纳入审核指纹；渲染中不再显示“请更新”的过期提示，隐藏旧预览并暂禁旧缩略图；个人预设复用应用的即时菜单控件 |

新版仍使用内置的几何示意家居背景，图中标注场景合成示意；可导入有使用权的真实背景。场景逼真度、任意透视融合和AI生成素材不是本次宣称已实现的能力。

## 使用入口

商品图片 → 选择模板 → 核对12页 → 使用此模板 → 按需编辑 → 应用更改 → 保存作品 → 导出JPG组/单张。

预设共享：我的预设 → 导出当前预设；另一台电脑使用“导入个人预设”。模板名字由用户填写，软件不会替用户判断自定义名字或任意手写文字是否包含客户信息。
