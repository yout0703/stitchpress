# 菜单交互复查与视觉优化

2026-11-12 · 0.1.0.dev4 → 0.1.0.dev5。延续17的五工作区架构，改善一期实际使用，不扩张二期范围。

## 复查结论

主要问题是参数过度纵向堆叠、按钮缺少主次，以及预览状态不可信。dev5已完成本轮修正；Mac本次检查未再发现阻塞所测路径的问题。这是本地设计与操作检查，不等于客户完整业务、Windows或辅助技术验收。

设计保持薄荷绿强调色、深浅双主题与原生桌面交互。用明确的字号层级、较轻的页签、固定操作区和适量留白组织内容。作品与实际预览承担视觉重点，参数仍保留明确标签和单位。

## 五步路径与结果

1. **进入作品：已改善。** 原界面以字段和按钮为主，缺少作品视觉。现在左侧确认来源和货号，右侧显示当前针格母版；导入XSD为主操作，下一步为次级操作。该概览不代替实际输出检查。
2. **设置印花与图纸：已改善。** 阅读设置按“页面/格宽”和“页边距/样式/字体”分为双栏。标题与页脚使用轻量页签和紧凑字体动作；已应用与未应用状态分开显示。
3. **配置符号与配线：入口保持稳定。** 沿用上轮独立分区与库管理菜单。本轮没有改动符号计算或材料口径；不以其他页的截图代替完整符号操作验收。
4. **制作商品图片：已改善。** 场景参数分双栏，内容与样式、输出尺寸、五张方图内容分别组织。选择场景二后，点击“查看实际商品图”直接启动场景二预览，原生已确认结果。
5. **检查并输出：关键误导已修正。** 目标切换时立即隐藏旧图片，明确要求刷新；参数未应用、后台生成、失败和迟到结果均有独立处理。保持固定检查/核对/生成入口，实际文件由现有核心生成。

## 问题、优先级与修正

| 发现 | 严重度 | 修正及验证 |
|---|---|---|
| 新预览标题下仍显示旧目标图片，容易误认输出 | 高 | 切换目标/页码、修改参数立即切换为空状态；未应用参数和不同目标的迟到结果拒绝显示。自动回归及原生切换验证 |
| “查看实际商品图”只跳页，还需寻找刷新 | 中 | 按当前场景选择目标并启动生成；原生场景二结果确认 |
| 没有修改也可应用；恢复后跳回第一个页签 | 中 | 无变化时禁用应用/恢复；空应用不增加历史修订；恢复保留页签。原生阅读倍率修改/恢复及场景页自动回归 |
| 阅读和场景参数过长，上下查找费力 | 中 | 按业务分双栏，保留滚动能力及固定操作区；大窗口原生和1280×800离屏检查 |
| 作品没有视觉中心、按钮等权、页签边框厚重 | 中 | 增加针格概览、明确导入主动作、较轻页签和统一间距；日夜主题截图复查 |
| 高频工作区缺少直接快捷键 | 低 | 查看菜单共用Command/Ctrl+1–5；Mac实际验证2、4、1切换，完整键盘/辅助技术另行验收 |
