# dev12 针格编辑与交互性能修复

## 问题与修复

本轮针对客户反馈的“针格编辑不可用、符号选择不直观、按钮等待时间过长”进行复现与修复。

- 原编辑台的替换按钮必须框选后才启用，未提供单格点击及明确的行列选择入口。新增单击选一格、拖框、行列范围对话框三种选区方式；选区显示一基行列范围。替换线色提供色块，留空仍明确代表不绣。没有实际变化的替换不创建修订；可撤销，保护区约束继续保留。底部工具按说明和操作两行排布。
- 原“调整所选符号”使用只有内部标识的系统下拉框。改为可搜索的彩色符号图块窗口，展示编号、原文件名及占用的线号；筛选后选中可见结果，中文“应用符号/取消”。已占用符号整体交换，两色都记录手动保护；一次操作只写一条历史。Qt 标准窗口加载中文翻译。
- `post_fingerprint` 原本借用设置导出，间接执行整个作品的压缩、反读和完整校验。改为纯内容指纹，保留原有指纹格式及失效关系；保存和实际导出仍完整验证。
- 同一 ICC 的屏幕转换重用有界变换缓存；同一窗口只缓存当前符号库和图块，资源字节或记录改变即失效。未改动的线色表、针格画布不重复创建。不可变母版的针数和内容哈希复用。
- 大作品的自动恢复副本在独立进程压缩，界面只准备不压缩的校验快照、核验并发布结果；同一时间只有一个任务，换作品/关闭时取消旧任务并清理临时快照，迟到结果不得回写当前作品。
- 商品预览和其他后台任务的输入快照改用不压缩的私有传输容器，保存的正式作品仍采用原压缩格式。此项针对进入商品页时额外出现的数秒等待。
- 大作品的菜单/快捷键/顶栏常用保存同样改为后台压缩，界面显示正在保存并允许继续修改；协调器仍持有实际文件锁并核验完整快照后原子发布，校验外部修改与历史副本。保存期间的新改动保持未保存状态，不用旧快照覆盖。重复保存无改动作品直接返回；程序内部同步接口和新建作品另存仍保留原语义。
- 尺寸摘要仅在界面保留两位小数，内部格距与实际输出计算保留精度，避免无限小数挤占编辑工具栏。

## 本地测量

本机 CT242（109×106 格、11,252 针、16 色、152 符号，作品包约152 MB十进制）实测：

| 操作 | 结果 |
| --- | --- |
| 普通刷新，优化前 cProfile | 3.371 秒，其中作品打包约2.53秒 |
| 普通刷新，优化后 cProfile | 0.084 秒 |
| 连续30次刷新，中位数 | 67 毫秒 |
| 连续30次线色高亮，中位数 | 3.8 毫秒 |
| 连续120次切页，中位数 | 4.2 毫秒；含首次商品预览准备，最大560毫秒 |
| 连续10次符号窗口，中位数 | 6.3 毫秒 |
| 额外1000次高亮/切页压力操作 | RSS约增加7.8 MiB，当前符号缓存固定152项 |
| 大作品后台恢复 | 准备快照约541毫秒，随后后台运行期间仍可切页；整个保存约8.9秒 |

以上为本机软件计时与短期压力测试，不是所有机器、所有作品的延迟承诺，也不等同于数小时内存泄漏排除。大作品保存/渲染仍有真实计算和磁盘开销；本轮消除的是普通交互中重复发生的压缩和转换。152个客户符号的屏幕转换与优化前逐像素相同。后台常用保存的独立基准：准备约699毫秒，含最终发布的最大事件间隔约1.13秒，其余后台期间事件间隔中位数约10毫秒；整次约10.7秒，保存后反读成功。完整验证和历史副本写盘仍有开销，后台并不代表保存已经完成。
