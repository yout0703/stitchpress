这份清单记录完整目标，防止做成只会导出 TIFF 的简化壳。A 表示参考软件静态证据，F 表示当前厂家需求，P 表示 StitchPress 增补；实际实现与验收状态以TODO为准，不能将需求表当作完成声明。

## 6 AI核心能力

以下A项为用户明确方向下的StitchPress设计，不声称参考APP具备。完整流程见 [10](10-AI制版与修订.md)，接入边界见 [11](11-模型接入与质量评估.md)。

| 编号 | 核心能力 | R1要求 | 验收组 |
|---|---|---|---|
| A01 | 自然语言理解与设计要求 | 把主题、构图、保留项、针格、色数、交付预设整理成可修改结构；缺失不猜成客户事实 | T14 |
| A02 | 来图识别与路径选择 | 区分平面插画、材质效果图、实绣照片、已有工程；已有干净蓝图优先复用 | T14 |
| A03 | 原创蓝图与来图重建 | 文字创作或目标图编辑，去除布纹/针脚材质，保留主体特征；输出候选而非生产母版 | T14 |
| A04 | 候选与版本比较 | 默认一张候选起步，可追加；保留采用/已展示版本与提示模板；不保证重新调用可复现同一图 | T14/T17 |
| A05 | 蓝图到DMC针格 | 本地确定性转换、明确W/H与目录、实际色数约束、细节保护；不能由模型直接编造整张针格 | T15 |
| A06 | 浅色主体与真实空白 | AI辅助标注候选，人工可修正蒙版；主体浅色有针、负空间受保护，不能自动填全部孔洞 | T15 |
| A07 | 原图/蓝图/母版模拟对照 | 整体和局部对照，识别关键对象遗漏、轮廓和细节变化，证据与坐标可追溯 | T14/T16 |
| A08 | 指令式局部修订 | 自然语言＋明确选区，输出可审阅补丁；区域外母版线色/针格保持，另存新版可撤销 | T16 |
| A09 | 可绣性与质量助手 | 本地针数、杂点、密度报告＋AI视觉疑点；给建议不自动删细节，不替代独立数字核验 | T15/T16 |
| A10 | 制版流程编排 | 分析→蓝图→转换→修订→检查→冻结→交付；阶段恢复、取消、有界重试和费用控制 | T17 |
| A11 | AI辅助商品素材 | 可生成背景与文案草稿，主体使用当前母版模拟确定性合成；规格数值来自SKU | T08/T18 |
| A12 | 模型配置与成本记录 | 按视觉/图像能力选择适配器；真实凭据独立保存，额度、用量、错误和跨端恢复可见 | T17/T18 |

## 7 参考之外的其他增补

这些不混算成参考 APP 已有能力：

- PDF 原倍率、当前母版白底 X 模拟、主体浅色与真实空白复核、客户 v10 预设：F。
- 可携带工程包、清楚的修改影响、材料规则版本、批量返单、分别记录数字/视觉/实物状态：P，部分基础来自 F。
- 符号形状相似性与邻色接触优化、纸面可读性评分：R2/P；R1 先提供局部检查与人工交换。
- 图片重建、文字创作、受控针格修订及AI质量辅助已提升为R1核心范围。通用自由编辑、多针法生产、库存采购、云协作与本地大模型运行时仍为R2候选。

参考 APP 的 30 万总格、200 页、512 库上限、8,000 万常规像素是其实现边界，作为试验输入参考，不直接作为 StitchPress 的性能承诺。整体范围调整需更新本表和验收，不以“阶段完成”掩盖仍缺少的功能。
