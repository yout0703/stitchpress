# 三轮界面精修与真实文件验证

2026-11-12 · 0.1.0.dev6 · 一期本地工作流。

## 本次结论与范围

用户提供的五张截图证明 dev5 的界面复查仍不充分：符号密集、数值字段无节制拉伸、CMYK 字段粘连、等效 CT 文本裁切和导入错误缺乏解释。此前 docs/18 的通过结论仅适用于当时所测路径，不能代表这些问题已经消失。本轮按实际内容、不同窗口尺寸和真实文件重新检查。

保留五个工作区与薄荷绿强调色，重点是可读性、信息层级和操作闭环。没有扩展二期 AI 或交付业务。所有客户图纸、图像、符号库、测试作品和截图仅保存在本机，不随代码推送。

## 五步路径复查

1. **作品：已改善。** 左侧用独立来源卡片区分图纸、原图和针格统计，右侧限制作品概览高度。导入主动作清晰，“更多”箭头位于右侧。首次从内置示例导入时，用图纸名称/文件名初始化名称和货号；已自定义的客户信息保持不变。
2. **印花与图纸：已改善。** 尺寸与布边分栏；数值输入按内容定宽；等效 CT 两行完整显示；标题与页脚分成文字/位置/印刷通道，CMYK 各通道标签在字段上方。长页面可滚动，应用/恢复始终在固定底栏。
3. **符号与配线：已改善。** 符号改成等尺寸、可搜索的图块；整数编号原值展示，隐藏 `int:` 类型前缀，原始标识保留在提示与数据中。映射表显示符号缩略图、线色、针数、绑定方式；减少表格网线，增加行高。空配线表有下一步提示。
4. **商品图片：已改善。** 场景、内容、输出尺寸及方图内容保持独立页签。内容页按文案/局部与配色分栏，按钮保持间距；数值输入不再占满整行。图库仍为示意场景，不冒充真实商品摄影。
5. **检查与导出：已修复阻塞。** 应用输出设置固定在滚动区外。真实点击发现默认新目录被错误拒绝，已将“生成安全文件名”和“验证用户目录名”分离；目录默认值和中文名称都能进入导出任务。尺寸摘要保留三位小数显示，底层计算精度不变。

### 格式支持边界

- XSD 仍限定已验证的 Pattern Maker v4 全针子集。完成已知小针、线段/结粒和特殊模型计数检查后，允许真实样本中共同出现的 `1/6` 尾部扩展封装；扩展内容不解释、不转换为针法，记录字节数与 SHA，完整原始 XSD 存入作品并可原样导出。
- 该扩展并未被完整逆向；这不是对任意 XSD 附加区的通用支持。未知封装、非全针、混线等仍拒绝。不能声称保留了原制图软件全部编辑/展示设置。
- OXS 新增纯 `commentsNN` 的 `format` 说明和空 `commentboxes` 容器兼容；未知格式字段、含子记录的说明节点、非空注释框以及非全针内容继续拒绝。没有放宽 XML 安全解析。
- 77 色图纸需要至少 77 个互异符号。自制 77 符号库仅用于验证容量，未加入应用默认资源，也不代表工厂可直接使用。
