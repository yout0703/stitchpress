# dev11 商品工作台、尺寸与精选场景

本轮范围为一期操作体验和离线挂画素材，不启用二期 AI 接口。

## 行为变化

- 商品页面改为左侧页面缩略图、中央画布、右侧参数检查器。选页联动对应场景；文字/输出尺寸/方图内容由检查器分区切换。
- 有效参数停止输入后自动生成整套草稿预览；刷新时保留上一张画面，状态条标明正在更新。过期进程结果不能覆盖新设置，取消不会改变作品。
- 应用设置与保存作品继续分开：预览读取临时设置，导出读取已应用的设置。现有模板/预设/字体/自定义背景仍可用。
- 尺寸页加入画心、四边留白、整布的比例图和数值。调用生产尺寸验证，转换单位继续沿用原有 Decimal 精度和留白基线，尺寸修改不改变母版针格。
- 增加 11/14/16/18 CT 快捷计算。输入不完整时清除尺寸图并解释问题，不展示上一次尺寸冒充当前结果。
- 增加四个精选场景：奶油客厅、亚麻卧室、绿意书房、暖木玄关。旧场景编号 0–8 保持，新场景编号 9–12；自选背景优先。
- 四个背景为原创生成的静态安装资源，离线使用，无账户、API、费用或客户作品上传。画作按原比例确定性合成，完整画框越界时报错，场景标注为合成示意。
- 新场景使用柔和阴影，内置背景文件哈希参与导出缓存依赖。旧场景渲染路径保留。
- 单张导出菜单使用中文页名；缺少来源图片的预览页面可以返回作品页补充。
