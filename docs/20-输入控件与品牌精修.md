# 输入控件与品牌精修

2026-11-12 · 0.1.0.dev7 · 一期界面改进。

## 输入控件

用户截图中的查图 DPI 数字贴左边缘，原因是 Qt 数值框的外框样式和内部编辑器分别处理布局；仅调整外框 padding 无法稳定设置内部文字留白。已给数值框内部编辑器明确设置左 10、右 4 像素文字边距，并通过应用事件过滤器覆盖后打开的弹窗与重建控件。

统一文本框、下拉框、整数和小数步进框的圆角、边框、焦点与禁用状态；右侧步进区独立预留空间。内部编辑器取消重复边框，数值框高度与普通输入框接近。页内定宽规则不再修改 Qt 内部编辑器，避免窄框溢出。阅读倍率和每格尺寸改为适合数据的宽度，较长默认提示保留简洁文字及完整悬浮说明。参数含义、取值范围和业务计算未改变。

## 品牌

采用新生成的交织 S 标记，深绿与薄荷色呼应现有日夜主题。图标与英文名称组成紧凑组合，中文“绣印工坊”置于下一行，右侧用细分隔线与当前作品名称区分。作品名和货号相同时只显示一次。

透明 PNG 已接入顶部品牌区和应用窗口图标；同源 ICNS/ICO 已接入 Mac 与 Windows 构建脚本。品牌资源在 `src/stitchpress/resources/brand/`。Mac 包内 PNG/ICNS 与源文件 SHA256 一致。生成图是含轻微色阶的透明位图，不宣称为矢量 Logo；字标由原生字体渲染。
