# dev21 内置彩色符号与客户试用包

2026-11-13 用户明确要求：客户152彩色符号作为内置默认库，不再使用黑白演示库，重新导出 Windows 试用包给客户查看。此前客户资源仅本地导入的限制，对这套资源由本次明确指令替代。

- 首次进入工作台和文件中新建作品都采用“客户152彩色符号库（内置）”，附共享 CMYK ICC；导入 XSD/OXS 时沿用该库。
- 选择符号库中始终提供内置彩色库。打开旧工程保留原符号和映射，用户明确切换才重新分配，旧库保留历史。
- 内置资源仅152个原字节图块和配套 ICC，编号类型及前导零保留。没有复制客户作品、其他备用库、参考软件代码、授权文件或密钥。
- 资源使用带 SHA256 清单的 tar.xz 固实压缩，仅内存读取，不磁盘解包；损坏则报错，不回退黑白库。启动后缓存一套不可变资源。
- 自动配色对同一库每批只创建一次 CMYK 到 sRGB 转换；三处代表图块逐像素比较旧调用输出一致，原图块和印花 CMYK 值不变。Pillow 官方用法通过 Context7 核对：[ImageCms 文档](https://pillow.readthedocs.io/en/stable/reference/ImageCms.html)。
- 发行继续沿用七天离线试用、公钥和签发流程，签发起连续168小时；不为客户提前生成授权，不解除到期锁定。
