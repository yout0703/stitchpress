# 工作流程与界面

设计v0.5：一期先复刻参考主要功能和操作，AI/统一作品库/我们的专用交付列二期，范围以02和TODO为准。保留已有现代双主题，不要求复制参考Tk皮肤。双端使用同一业务路径，快捷键和系统文件对话框可遵循各自平台习惯。

客户现阶段仅用Windows，客户操作说明、教程截图和交互验收以Windows为主；Mac日常开发保持同页面结构、字段和动作，不单独设计另一套制版流程。系统快捷键、窗口装饰和文件选择框允许遵循平台惯例，具体安排见07。

## 1 总体信息结构

**2026-11-12调整：** 以下六页为dev3历史结构；新的五工作区、菜单归属和交互规范以 [17-信息架构与现代工作台](17-信息架构与现代工作台.md) 为准。业务功能保留，文字归排版、配线归符号，避免两套导航并存。

一期主导航必须直接到达以下六个功能页，能按参考操作完成任务，不以深层弹窗或已有底层函数替代：

| 功能页 | 可见操作 |
|---|---|
| 文件与作品设置 | XSD/对应图/名称/货号/目录、设置保存/打开/另存、预设列表/保存/应用/移除/默认；客户试用版增加离线机器码/授权状态入口，未激活或到期时锁定业务 |
| 画布与图纸 | CT/宽度、四边留白、生产DPI/查图DPI、cell_mm、纸张/方向/页边距/重叠/样式、检查尺寸 |
| 文字与配线 | 顶底独立显示/字体/字号/颜色/对齐/偏移/占位符；CT列表及每米针数、配线预览 |
| 符号库与分配 | 库选择/文件夹导入/版本编辑、左库右DMC、放大/自然排序、颜色匹配/指定/交换/重分配 |
| 出图预览 | 画布/整张及分页图纸/符号表/卡/电商目标、页码、刷新/缩放/过期状态 |
| 电商图片 | 7+5/分组/单张、三场景可视模板选择、自选/恢复背景、相框/卡纸/位置、详情尺寸、文字/DPI、五槽内容/注意事项 |

全局保留生成全套、阶段进度、安全取消、错误记录和打开结果文件夹。具体布局可沿用现有工作台与侧栏；必须覆盖上述操作，不要求六个页面完全照抄参考。

二期导航才扩展统一作品库、AI制版、全局资源/预设、任务中心、模型用量及我们的交付中心；这些缺失不冒充参考未完成项。原设计的工作区说明如下，涉及AI/SKU/专用交付均按二期解读。

当前作品工作区包含：文件与规格、画布与查图、文字与图例、符号与材料、商品图片、版本与交付。中心持续展示预览，右侧编辑当前参数，顶部显示作品/规格/版本，底部显示检查摘要与导出入口。宽表和大图允许独立展开，不让窄侧栏截断DMC或符号。

```text
作品/规格/版本       保存草稿   查看修改   预览   导出
────────────────────────────────────────────────
分组导航       全图 / 分页 / 局部预览          当前分组参数
              缩放、网格与空白检查          单位、来源、重置
────────────────────────────────────────────────
有效针数 / 色数 / 尺寸 / 页数       当前检查问题与任务进度
```

这是内容结构示意，不是已选定的最终视觉稿。

## 2 一期：从XSD或作品设置开始

1. 选择支持范围内的XSD，或打开本软件已保存的作品设置；检查格式、原件与库版本，显示W/H、色数、针数和异常。
2. 选择对应原图，候选文件与货号建议只供人工确认；核对作品名、前导零货号和输出目录。
3. 设置CT或画心宽度、四边留白、独立生产/查图DPI、cell_mm/纸张/方向/页边距/重叠与查图样式。
4. 在文字与配线页填写顶底独立文字/字体及占位符、多CT和对应每米针数；未知材料系数不伪造。
5. 在符号页选/导入库，颜色接近自动匹配或指定/交换，查看完整DMC对应与符号放大；保存库新版本。
6. 在电商页配置三场景/框型/背景及局部、7+5内容、尺寸/文字/DPI；在预览页检查指定目标和页码。
7. 保存作品设置及映射，再按06第0节生成参考全套或所选商品目标；完成后打开目录。错误/取消保留明确记录，未完成集合不能冒充完整成品。
8. 重开已保存设置可返单；输入移动/损坏或错库时给出修复入口，不要求用户先配置AI或使用我们的N+6包。

现有原生.stitchpress仍可打开，不回退已有数据；二期自包含工程/多SKU/专用交付从此基础继续。软件不要求客户安装Python，输出目录可选，不强制写安装目录。

## 3 工程导入细节（XSD一期，OXS二期增补）

导入前显示支持格式与针法范围；导入后给出版本识别、W/H、实际用色、针法数量、空白和异常。用户确认对照原图、作品名、客户货号，再绑定符号库与工厂预设。

若缺失原图，仍可用母版模拟做生产预览；依赖原图的对比图和原图归档目标显示缺项。不能因缺原图使本可完整表达的针格工程丢失。选择普通图片时可进入AI制版或只作对照；明确“尚无母版”，完成转换与审核冻结之前不可直接导出生产。

未支持针法、重复/越界坐标、线色身份冲突或格式损坏都显示问题详情；能修复输入时重新导入，不能继续导出一份遗漏针法的“成功”包。

### 二期：从图片或文字进行AI制版

1. 选择“客户来图”或“文字创作”；设置目标针格、色数上限、目录与客户预设。
2. 查看模型整理的设计要求和保留项，可编辑；选择复用干净图或重建蓝图。
3. 选择服务和本次候选/迭代额度，启动已配置的阶段；显示输入范围和用量。
4. 在原图与蓝图候选间比较并采用；已采用候选保留，重试不覆盖。
5. 本地转换针格，显示浅色主体、负空间、低频颜色及细节检查。
6. 原图/蓝图/母版X模拟对照；选择区域后输入修改要求，查看逐格差异与外区保护结果，接受或撤销。
7. 完成硬检查与内容审查，冻结母版，进入当前作品的生产与交付设置。

中央对照图可同步定位同一对象；区域坐标经过裁切/缩放后需转换，不直接把模型框当网格索引。指令栏显示基准修订，结果迟到时进入原分支候选，不覆盖新母版。完整行为见 [10](10-AI制版与修订.md)。

AI任务状态和本地导出状态分开展示；“候选生成完成”不显示“可生产”。模型连接页分别配置理解、生成、编辑能力，提供实际能力检查，不把文本连通当成全功能可用。

## 4 字段与配置

### 文件与规格

| 字段 | 输入与交互 | 校验及影响 |
|---|---|---|
| 客户号、内部ID、款名 | 客户号文本、内部稳定ID、可选中英文名称 | 保留前导零；生成文件名另做跨平台清理，不改原货号 |
| 母版与对照图 | 导入、查看来源、换源产生新修订 | 显示当前针格/色数及人工对应确认；输入变化使相关产物过期 |
| 规格名称、布料、名义CT | 预设与自定义 | CT与实际格距分列；不能只换标签保持错误尺度 |
| 尺寸方式 | 理论CT、实际格距、目标画心宽度 | 显示推导结果及参数来源，冲突必须解决 |
| sx/sy、四边留白 | 格/cm/mm，保留原单位 | 即时显示画心、整布和预计像素 |
| 工厂预设 | 应用、另存版本、恢复当前草稿 | 明示将改变哪些字段；不迁移旧任务 |

### 画布与查图

| 字段 | 客户操作 | 校验及影响 |
|---|---|---|
| 生产DPI、ICC、黑色策略、压缩 | 选择工厂方案，高级项展开 | 与预设兼容；不以更改标签代替重渲染 |
| 生产网格、框、刻度、裁剪线 | 各自独立开关和物理宽度 | 当前厂家无内部网格；不占针格或改变整布尺寸 |
| 查图模式 | 原倍率 / 阅读放大 | 阅读放大不能被误当布面印花文件 |
| 纸张、方向、页边距 | A4/A3/A2/自定义 | 显示可用区域、实际格子尺寸和最终页容量 |
| 重叠格 | 非负整数，明确重复区域 | 当前厂家为0；配线不重复计数 |
| 图例与字体 | 完整图例、列数、字体字号、位置 | 先重排后计算页数；溢出定位字段，不静默缩小 |
| 标题页脚 | 文本、显示、颜色、字体、pt字号、对齐、偏移 | 可用占位符菜单；未知占位符或放不下就提示 |

占位符至少包括 `{title}`、`{code}`、`{width}`、`{height}`、`{colors}`、`{ct}`；建议增加实际格距、画心尺寸、页码、页数。区分“可用于单页”和“可用于整个作品”的变量，禁止把未展开花括号直接印出。

字号使用pt或mm表示用户意图，最终记录渲染像素；300DPI厂家字号下限按预设检查。不能把现有脚本的36px直接当36pt。

完整厂家字号及DPI换算见 [03](03-十字绣业务规则.md) 的“当前厂家字号基准”；输入低于对应下限时定位字段，不能自动缩字继续发布。

### 符号与材料

左侧为符号库缩略图与放大区，右侧表格列出显示序号、DMC文本、绣线色块、针数和符号。支持排序、选中线色高亮全图、交换、锁定手动项、重新自动分配。

符号库编辑先创建新版本并预览影响；已被历史项目引用的旧版本不能物理删除导致无法返单。资源列表可隐藏不用的库，作品包仍保有必要快照。

材料页默认针数模式。开启估算后需选择规则、布料/CT、股数口径、系数单位、损耗是否已含、固定余量与包装步长。展示一行公式计算过程，原始针数永远可见；无效规则不输出伪精确米数。

### 商品图片

2026-11-12新增一期要求：顶部先选择整套模板，再查看7详情/5方图缩略图和当前页预览，右侧仅配置当前页。首批至少四套独立版式，支持另存个人预设、应用/取消/撤销和保存恢复；场景/相框是模板内的局部设置。AI设计模板、生图和文案增强属于二期。完整交互与覆盖项保留规则见[22](22-电商多模板与AI增强.md)，当前尚未实现多模板入口。

详情目标有7项，方图槽位5项；每个槽位可切换内容。三张挂画各自独立选择背景、框型、缩放和偏移；可自选背景，调整框边/卡纸；局部中心与倍数可在图上选择。

场景类别拟覆盖客厅、卧室、书房、现代灰调客厅、新中式玄关、儿童房、原木餐厅、法式奶油客厅和展厅。框型拟覆盖简约黑框、原木浅框、胡桃木框、白框、香槟金框、银色细框、复古金框和深棕宽框。类别参考原APP，具体图像与框体独立制作，不使用其资源副本。

两类输出用途（不计为多套视觉模板）：

- “参考电商”：详情默认1200×1600，方图固定800×800。
- “3:4展示”（二期增补）：全部按明确的3:4像素规格输出；不强行把800方图填入3:4槽位。

显示源类型：对照原图、当前针格X模拟、可选点图、真实实绣照片。规格数值自动引用当前SKU；洗护正文可分段编辑，模板只提供措辞结构。对照图和实际规格不一致时，不自动声称精确实物比例。

## 5 预览的三种尺度

| 模式 | 用途 | 必须提示 |
|---|---|---|
| 适应窗口 | 查看布局、完整构图和页数 | 当前缩放，缩略图不能判断细符号实际清晰度 |
| 100%原像素局部 | 检查输出像素、笔画和格线遮挡 | 100%是图像像素比例，不等于屏幕实物厘米 |
| 校准尺寸辅助 | 用户按屏幕校准后辅助查看物理大小 | 仍以实际打印校尺为准，不保证系统缩放/屏幕PPI准确 |

空白检查可临时用对比底色、高亮无针格或显示DMC3865，辅助发现浅色主体缺针；这些检查叠层不能混入正式包装模拟或生产文件。

修改后预览标为“待更新”；每次预览绑定参数指纹，迟到的旧任务结果不得覆盖新预览。正式导出前固定本次快照及目标清单。

## 6 导出、批量与返修

一期目标选择为参考全套或所选商品目标，具体目标按06第0节；二期追加厂家N+6、PDF/OXS、双语说明/ZIP、补件和可携带工程。既有这些目标保留独立标识，不替代参考全套。

二期统一任务中心逐款列出阶段、输出数、耗时、失败原因与重试，不只展示不准确的全局百分比。导出期间允许编辑下一份草稿，当前任务不随之改变；重复提交相同快照显示已有任务/结果，用户可明确生成新包版本。

UI保存、AI返回与后台任务登记统一经项目提交协调器。保存冲突时保留用户未提交编辑并显示差异；其他窗口打开同一可写项目时只读或另存。更改减色/蒙版并重新转换时，显示原针格修订的保留/冲突情况，新候选经重新审核后采用，见05单写入规则及10第7.5节。

取消后显示哪些阶段已完成、哪些产物未发布；正在写入文件完成一个安全步骤后停止。失败或部分完成不会以正式完整包出现。只补文件按依赖图判断重做范围，结果汇入新的整包清单。

## 7 项目、交付和反馈

版本页显示“改了什么→哪些产物受影响→本次产物及检查”。客户外观认可、已发客户、工厂试印、校尺、套准、洗水分别填写，允许照片/说明作为附件并指向对应文件哈希。

默认不会发邮件、上传云盘或通知客户。客户选择导出到哪个目录，就只写入该位置及应用自身工作目录；诊断导出不包含授权凭据和不必要的私人路径。

## 8 错误处理与可用性

| 情况 | 产品行为 |
|---|---|
| 缺少字体 | 显示受影响版式，选择已导入可发行字体；不能静默替换后继续使用旧布局 |
| 目录只读、磁盘不足、文件被占用 | 保留任务快照，给出路径/所需空间估算/重试入口 |
| 母版/库哈希变化 | 隔离受影响缓存，提示重新导入或恢复原资源，不继续混用 |
| 图例/文字溢出 | 定位对应页和字段，建议增加空间或减少每页格数 |
| 色数超过库容量 | 显示差额；换库或进入设计修订，不共用符号 |
| 授权过期或无效 | 2026-11-13改为锁定业务，仅开放授权恢复等入口；保存独立恢复草稿，保留既有工程和成品，详见31 |
| 应用崩溃后重开 | 识别上次未完成任务，可清理或恢复经核验的检查点 |
| AI网络失败、结果未知或额度耗尽 | 保留输入和最好候选；不提交新调用；可继续已有蓝图/母版的本地工作 |
| 图像候选改动超出选区或无法对齐 | 展示差异并隔离候选，不自动写回；可重试或作为独立整体方案审查 |
| AI建议修改针格/线色 | 先展示明确变更范围和后果，接受后另存修订；不覆盖冻结工程 |

表格操作支持键盘、可读焦点和清晰单位；颜色之外还有符号、文字和高亮边框。长货号、中文文件名、大字体与双端高DPI缩放均进入验收，不靠截图观感代替。
