## 本轮修复

1. **大型保存与设置导出阻塞。** 大作品另存及作品设置 JSON 使用独立进程和点击时不可变快照；运行中可编辑/切页，后续修改不被覆盖；关闭和重复导出有保护。设置验证使用无压缩容器，去掉同次重复校验，原子发布及拒绝覆盖不变。
2. **原图与文字状态。** 选择原图立即刷新文件名和确认框；替换后清除旧确认。校尺及经典商品规格厘米文本最多四位小数，内部 Decimal 几何不变；真正规格方图 square-5 有渲染回归。
3. **保存时的幽灵未应用状态。** 配线统一 tuple；空 freeze 审核键按删除处理；后台候选与最终提交语义一致，兼容旧草稿。未应用参数会定位到对应设置页，避免笼统阻止保存。
4. **符号与取消反馈。** 坏符号改中文说明并带文件名；刷新保留有效选择，搜索隐藏或换库无对应符号时清空旧预览。安全取消的进度、任务和中文窗口状态一致，不再误报失败。
5. **历史恢复完整性。** 补 post、post_review、原稿、手工映射与匹配策略，重建表单同步；旧提交显示提交号 / 时间。恢复不写原件。再次打开当前文件时，真正还原已保存状态并保留现有写锁，修复确认放弃后仍留着草稿的问题。
6. **主题与预览生命周期。** 全局样式和字体仅初始化一次，同主题不反复铺 QSS。主窗口关闭、模板对话框结束及编辑器替换时显式终止预览、停计时器并阻止排队重启，避免已销毁控件仍被回调。测试夹具另显式处理 DeferredDelete，避免测试窗口跨用例积累。
7. **版本与诊断。** 同步运行时版本，并在构建前及打包 EXE 冒烟核对 pyproject 版本；CI 保留测试实时日志。此前 dev18 的 25 分钟超时与版本标识候选都未作为最终交付；没有删测试或扩大测试限时。

涉及 Qt 行为的依据：[QApplication 全局样式](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QApplication.html)、[processEvents 与 DeferredDelete](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QCoreApplication.html)。
