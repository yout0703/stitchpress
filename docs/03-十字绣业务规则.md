# 十字绣业务规则

本文把实际生产中的区别转成产品规则。通用数据规则与“EVERFLOW 合作厂家 14CT v10”专用值分别表述，不能互相覆盖。来源见 [00](00-来源与证据.md)。

## 1 四类业务对象

| 对象 | 包含内容 | 变化的影响 |
|---|---|---|
| 设计母版 | 针格宽高、每格线色、针法、空白、线色身份与数字RGB | 改变图案或材料统计，产生新设计修订 |
| 产品规格 SKU | 客户货号、布料、实际格距、股数、留边、材料规则 | 同一设计可形成不同产品规格 |
| 生产方案 | 符号映射、印花色彩、DPI、网格、校尺、查图排版 | 改变相关生产/查图/材料显示文件 |
| 导出批次 | 精确输入快照、产物组合、版本、检查与发布结果 | 是一次可追溯出单，不能代替设计身份 |

返修、重新压缩、增加一页说明不新建同款货号；同款不同 CT 可有不同 SKU。客户号保持原字符串，内部 ID 与显示名分开。

## 2 针格和空白

- 全针母版的 `labels[y][x]` 指向色板项，`-1` 表示无针。RGB 白色、透明显示色和无针不是同一概念。
- 一个完整十字计一针；不按两条斜线计两针，不乘股数。总格数为 `W×H`，且 `有效针格 + 空白格 = W×H`。
- 背景留白、布料余量不计针。DMC 白色/米白表面要有线色与符号，正常计针。
- 半针、四分之一针、petite、回针、结粒、珠等单独建模；R1 全针生产链遇到这些内容明确拒绝，不能以空数组占位表示已支持。
- 输入解析器需要识别或报告未知针法/记录；只统计自己认识的全针后返回成功属于错误导入。
- 图片没有针格信息时不能直接出生产包。需要另建、审核可绣母版；AI 展示和图片重建不等于还原原作者逐针工程。

### 主体浅色与负空间

蝶翼、花瓣和动物身体上的浅色表面仍应绣制；叶片之间、物体之间的真实露布保持空白。连通性、颜色阈值、封闭孔洞只能提示疑点，不能一键判定是否补针。

当前厂家确认的内部米白为 DMC3865；这是该合作的白色处理规则，不把其他作品已有的 B5200、Blanc 或浅色自动替换成3865。补针进入新母版修订，保留精确坐标或蒙版、背景保护区和增量针数，重新导出所有相关文件。

## 3 线色身份与印花符号

| 名称 | 含义 | 不能用什么代替 |
|---|---|---|
| DMC代码 | 线材身份，按文本保存，连同品牌与目录版本定位 | RGB、数组位置、图例序号 |
| 色板索引 | 本母版里被格子引用的位置 | DMC号或全局库ID |
| 符号外部ID | 某一符号库里的原始标识，可不连续 | 自然排序后的行号 |
| 图例序号 | 展示顺序，通常从1开始 | 符号ID |
| 印花墨色 | 印在布上的识别信息 | 最终绣线实际颜色 |

线色库允许不同代码具有相同 RGB。当前 455 条目录的原代码、名称、RGB 与原顺序保留，不按 RGB 去重、不补零。设计中若同一线色身份分裂成多项，显示冲突并通过明确的设计修订合并，不在导出器里偷偷处理。

同一作品的一种有效线色对应一个唯一符号，符号数量不足时不能复用符号或删色。DMC 排序是显示规则，不改针格所指色板项。

符号导入：TIF/PNG/BMP；单页、尺寸和ICC有效性检查；拒绝空白及像素完全重复项。相似而不相同的符号仍需可读性检查。新符号保存为库的新版本，旧项目继续使用原库快照。

`024.tif` 的外部ID可为整数24，而 `0.1.tif` 对应字符串 `"0.1"`。内部采用稳定字符串键并保留原ID类型/原文件名，禁止转float/int截断。算法需区分 `"0.1"`、`0`、`1`；资源加载与保存往返不能改变其身份。

### 自动分配

R1 优先保证一一对应、原绑定稳定、手动项优先和结果可恢复。参考 APP 的平均符号颜色贪心匹配可作为一种候选策略，不把它宣称为最佳可读性。

初次自动分配记录算法版本；重复导出不重排。手动交换两项应整体提交，不能在中间状态形成重复。重新自动分配显示变更列表，另存映射版本。R2 再评估形状相似度、邻色接触、局部密度和小符号可读性优化。

## 4 布号、实际格距与画心尺寸

三种尺寸输入方式：

1. 按名义 CT 理论换算：`s = 2.54 / CT`，单位 cm/格，注明“理论格距”。
2. 按客户实际格距：分别保存 `sx`、`sy` 的十进制字符串与来源；显示等效 CT，但不覆盖实测值。
3. 按目标画心宽度：`sx = width_cm/W`；默认保持正方格，反算名义值供参考，需要与真实布料核对。

如果产品采用跨多根纱绣制，布料 thread count 与 stitches per inch 不能直接等同。R1 的布号界面明确以针格密度为口径；复杂布组织通过明确实际格距表示，不猜测 over-two 的意义。

```text
画心尺寸 = (W × sx, H × sy)
整布宽 = 画心宽 + 左留白 + 右留白
整布高 = 画心高 + 上留白 + 下留白
```

留白允许按格数或 cm/mm 输入，并保存原输入单位。切换显示单位不反复取整、更不能悄悄改动实际尺寸。客户可分别指定四边；X/Y 不同格距必须明确展示，不静默拉伸成方格。

### 当前厂家预设

名义14CT、实际 `sx=sy=0.181 cm`，四边各30格，即各5.43 cm。240×320格样例画心43.44×57.92 cm，整布54.30×68.78 cm。

采用客户值，不用理论 `2.54/14` 替换。将这个预设切换成其他 CT 时必须明确选择新格距来源，不能只改“14”的文字。

## 5 像素坐标与校准

对实际位置用十进制累计并 `ROUND_HALF_UP`：

```text
px(cm) = ROUND_HALF_UP(cm / 2.54 × DPI)
X[i] = px(左留白cm + i × sx)
Y[j] = px(上留白cm + j × sy)
```

不能将每格四舍五入后再乘格数，否则长幅累计偏移。当前预设单格约21.37795 px，所以正常存在21/22像素宽高组合。生产与原倍率查图要共享全局坐标相位，分页在已有坐标上裁切。

300DPI 的240×320样例整布为6413×8124 px。DPI改变渲染像素，不改变设计针数；只改 TIFF 标签不会得到重新绘制的有效分辨率。

校尺长度从同一格距计算：当前100格=18.10 cm。画布尺度与设备校准分开；如需设备X/Y补偿，作为独立、有版本的高级设备配置，不修改设计W/H或名义CT，不默认应用未测补偿。双端导出均要求打印 Actual Size/100%；不能保证打印机驱动自动遵从。

## 6 生产、查图与色彩

生产文件用于布面印花，查图用于纸面阅读；各自有独立配置和用途标识。放大查图格子不改变布面印花尺度。

当前厂家预设：

- 300DPI、8位四通道CMYK、单页LZW TIFF，嵌入客户 Japan Color 2001 Coated ICC。
- 无墨白为 `(0,0,0,0)`；黑文字、网格、刻度及确定为黑的符号笔画为 `(255,255,255,255)`。这是本客户的四色黑要求，其他客户可选择自己的黑色策略；不能因存在K通道就把彩色笔画刷黑。
- 生产版无内部网格，保留外围坐标、连续刻度、闭合画心框及整布外缘红裁剪框。图例为 No./Symbol/DMC，不显示针数。
- A4查图有每格细线、全局十格粗线、完整图例、页码、范围、邻页和校尺。原倍率、不重叠，边缘页留白。
- 图像/PDF/Excel标签英文，说明中英双份。语言是预设选项，不限制软件中文界面。

RGB对照图、绣线数字RGB和CMYK印花各自保存来源与配置。屏幕预览转为sRGB，不能用屏幕颜色保证布面墨色或实物线色。提高DPI不能恢复20×20原始符号不存在的细节；生产符号默认最近邻，平滑缩放仅在明确允许的阅读/展示样式中使用。

### 当前厂家字号基准

以下值来自v10的`typography`，图像字号以300DPI下的渲染像素表示；预设初始化采用此值，客户调整时按其下限核验，不转换成同数值pt。

| 用途 | 300DPI基准/下限px | 等效pt |
|---|---:|---:|
| 生产外围坐标 | 48 | 11.52 |
| 生产图例序号 | 50 | 12.00 |
| 生产图例DMC | 56 | 13.44 |
| A4坐标 | 36 | 8.64 |
| A4图例序号 | 36 | 8.64 |
| A4图例DMC | 39 | 9.36 |
| A4页码 | 34 | 8.16 |
| A4其他数字 | 32 | 7.68 |

Excel正文为14pt。图像字号`pt=基准px×72/300`；通用预设采用其他DPI时保持物理字号，渲染像素下限按`ceil(基准px×DPI/300)`，布局使用实际字体文件度量。当前厂家兼容模板仍固定300DPI；改DPI应另建通用模板。不得靠缩字满足图例容量，印刷清晰度还需视觉检查。

## 7 分页与图例

布局先测量文字和实际图例，再求每页可用列行；不能把当前29–31色样例的100×110格容量写死到66色矮幅作品。图例增加时重排或减少每页行数，不缩格、不藏色、不把规定字号缩到难读。

无重叠模式：全图每个格恰好归属一页。重叠模式：另外记录每页独占核心窗口与重复显示窗口，核心仍恰好覆盖一次；可见区域的重复次数按计划核对，重复格不重复计入全图配线针数。最后一页不拉伸填满纸张。

全局数据窗口用0基半开区间，客户阅读用1基针格编号。边界线100和第101列不是同一个对象。每页同时给出页号、行列位置和邻页，避免只有孤立页码无法拼接。

## 8 配线与包装

逐色针数是确定值；用线量是与材料和绣法有关的模型。R1 提供两个模式：

| 模式 | 行为 |
|---|---|
| 针数清单 | 默认；逐色整数、SUM总计，无未经确认的线长 |
| 材料估算 | 客户配置经过定义的公式、系数、单位、股数、损耗和包装取整后启用 |

基础系数模型定义：`c` 为指定布格/股数/线材下每“工作米”可绣完整十字数；`工作米` 是多股合用后的长度还是单股总长必须声明。股数若已包含在c的口径内，不再乘一次。

可配置的一种计算顺序为：

```text
基础工作米 = 该色针数 / c
建议工作米 = 基础工作米 × (1 + 损耗率) + 该色固定余量
包装工作米 = ceil(建议工作米 / 包装步长米) × 包装步长米
```

规则记录“c是否已含损耗”，避免重复加损耗。未使用色不加固定余量。绞数、股数拆分、线轴换算只有在供应规格和可拆分口径明确时启用，不能默认“所有DMC一绞都可按同一种方式分配”。

参考 APP 的9CT=90针/米、14CT=180针/米是其客户系数，不成为我们的全局默认。材料规则按CT分别计算，不能把14CT结果按画幅面积简单缩放给9CT。

## 9 展示与实物反馈

厂家包装模拟必须按当前母版一格一颗X、保留DMC/RGB和无针位置；当前厂家预设纯白背景、PNG、严格3:4、只扩外部白边，不改针格来迁就画幅。它是确定性模拟，不是实绣照片或色样校准。

商品场景可使用对照原图、当前X模拟或可选点图样式，始终标明来源。注意事项中的水洗、熨烫、褪色等依据具体材料填写，不由软件替所有材料作统一承诺。

数字核验、人工外观检查、客户外观认可、已交付、设备试印和洗水结果分别记录。生成成功、备份成功或客户看过效果图都不能自动推导工厂量产通过。

## 10 AI制版的业务约束

AI入口与已有工程入口最终都汇合到审核后的冻结母版。模型可以重建蓝图、给出浅色/负空间候选和局部建议，但不替代针格转换、DMC目录身份、计数、格距及生产文件校验。完整流程见 [10](10-AI制版与修订.md)。

采用蓝图需要保存实际图像和来源；从客户效果图重建的设计注明重建性质，不声称恢复其原供应商逐针矩阵或原线号。AI修改固定针格内的细节时不能擅自扩大W/H或超出所选符号库容量。

局部补针/换线色通过有范围的精确补丁形成新修订；区域外的针格、空白、DMC和RGB保持。只保持蓝图外部像素仍不够，整幅重新量化可能产生外区变化，因此最终对母版逐格检查。修改色板中被区域外引用的项视为越界的全局修改。

AI视觉意见与数字核验分别保存，模型的数量、定位和“合格”判断不作为生产事实。母版冻结后，包装模拟来自该矩阵，不能再经生成式重画替代。所需试印与材料验证不会因为增加AI而减少。
