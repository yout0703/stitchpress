# 桌面界面与双主题

日期：2026-11-11。用户选定本轮视觉探索中第2张“深色专业制版台”，并要求支持白天与夜间。此文记录已实现的Mac界面改造，不替代04中的完整产品流程与未完成需求。

## 结构与操作

- 顶部文档栏：作品与货号、保存状态、母版文件菜单、交付、AI助手、主题切换、保存和审核冻结。
- 视图工具栏：当前真实针格与尺寸、选区/平移、缩放、100%像素、适应画布、原图对照和规格抽屉。
- 左侧线色表：搜索线号/名称、色块、针数和实际符号；选色高亮与画布同屏，可清除高亮或调整符号绑定。
- 中央画布：仍使用真实针格矩阵的确定性预览。没有采用设计稿中的AI白兔图片替换业务母版。
- 底部固定修订栏：选区格数、替换线色/留空、替换和撤销。没有有效针格选区时不能修订；切换工程清除旧选区。
- 规格与转换：可滚动的右侧抽屉；作品元数据、实际格距、四边留白、蓝图选择与转换参数集中管理。
- AI页保留明确的单次调用入口、费用与附图选项；交付页显示当前母版摘要、审核状态、导出动作和任务日志。

## 双主题契约

| 用途 | 夜间 | 白天 |
|---|---|---|
| 背景 | #141a20 | #eef2f4 |
| 面板 | #1c232a | #ffffff |
| 画布外围 | #10161c | #e2e8eb |
| 文字 | #eef3f6 | #1b2933 |
| 主色 | #86deca | #176956 |

两套主题使用相同控件与布局，覆盖菜单、表格、输入、对话框、禁用、焦点和选中状态。QtAwesome Material Design Icons 6提供高DPI图标，系统字体按平台回退。

主题记录在本机settings.json的appearance.theme中，不写入作品。保存时合并现有设置，保留AI配置；不读取或更改系统安全存储。首次默认夜间，非法旧主题值回退夜间。当前为手动切换，尚未增加自动跟随系统主题。

换肤不重新量化，不改变源图、针格、线材RGB、ICC或导出配置；保留当前选区与缩放。业务库与符号缩略图不做深色滤镜。

## 实现与验证

appearance.py集中颜色与Qt样式；workspace.py构建控件层级；desktop.py保留协调、作品和任务处理。沿用PySide6 Widgets，无WebView、第二套前端或业务核心迁移。

72项自动检查通过；Mac原生窗口验证主题切换与重启记忆、搜索、框选、替换/撤销、规格抽屉及AI/交付导航。修复了无障碍切换只改变checked状态却不触发页面的信号绑定，以及长下拉框导致的抽屉横向溢出。窗口最小尺寸为1100×720；该尺寸仅做Qt离屏布局检查，Windows的100%/125%/150%缩放仍待实际验证。

安装包在dist/macos/StitchPress.app。验收时为区分本机旧安装副本，另复制了只修改包标识/显示名的StitchPress Preview.app；应用代码与最终构建相同。设计稿、原始截图、对照图、哈希和构建回执保存在reports/local/ui-redesign-2026-11-11，不进入Git。
