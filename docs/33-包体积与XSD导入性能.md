# dev22 包体积与XSD导入性能

2026-11-14。用户反馈 Windows 导入 XSD 慢，要求同时评估安装包体积。保持七天离线授权、彩色152库、原始图块、中文输出字体和生产规则。

## 已测基线

- dev21 Windows ZIP：109,656,116字节；解压文件合计243,514,529字节，1457个条目。
- 参考软件EXE：54,801,741字节，CArchive包内未压缩数据合计104,030,605字节；这不是现场运行后磁盘占用的测量值。静态目录确认参考使用Tkinter，本软件使用Qt Widgets，两者运行库不同。
- 内置152符号压缩资源438,340字节；体积主要来自Qt、Python、NumPy/OpenBLAS、图像编解码及字体，不是彩色符号本身。

## 导入瓶颈与修复

- 220×220/77色样本的界面填表循环反复调用`self.design`，一次导入约256次重建/校验整张母版。改为同一轮刷新共享不可变Design及已有统计。
- XSD导入原先先编码整个临时ZIP，再解码自检；其中有约88MB符号资源。新增内存内容检查，保留实体、路径、大小及不可变资源检查，不再为导入生成临时ZIP。真正保存仍保留容器往返校验。
- 去除导入后重复刷新；复用窗口符号缓存及经过验证的内置不可变资源。只在记录严格相等且每份资源字节对象身份一致时复用；磁盘作品的新字节或替换资源仍完整解析，特殊ID类型不合并。
- Coordinator从本次实际解码的快照SHA初始化，不再重复读一次大文件，也避免两次读取间的外部替换被错误接受。
- 增加实际EXE内部性能诊断：独立XSD导入和220×220/77色界面接管；继续受授权校验控制，诊断不写客户生产文件。

## 包体积优化

依据PyInstaller官方`--exclude-module`机制，只排除当前界面不使用的Tk、QML/Quick、Python OpenGL控件和未提供入口的AVIF插件。保留Qt核心/Widgets/Gui/Svg、平台及图像插件、软件OpenGL后备、NumPy、ICC、中文完整输出字体、现有PNG/JPEG/TIFF/BMP/WebP与PDF/Excel功能。Windows仅保留实际使用的`qtbase_zh_CN.qm`；Mac不在签名完成后裁剪资源。

参考：[PyInstaller选项](https://pyinstaller.org/en/stable/usage.html#cmdoption-exclude-module)，已通过Context7核对。发行后新增QML/GL/AVIF功能时必须重新调整此清单。
