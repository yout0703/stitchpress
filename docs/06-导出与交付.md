# 导出与交付

导出目标由模板定义，文件均绑定当前任务快照。完整包、单项补件和可携带工程包分别操作，不能将内部工程资源混入厂家日常成品。

已有工程和AI制版共用相同交付合同。AI图片必须先形成审核后的母版；蓝图、候选、蒙版、提示记录和模型诊断保留在工程中，不混入厂家N+6包。来图重建的双语说明注明设计来源与重建性质，不声称恢复原供应商逐针工程。

## 1 文件目标

| 目标 | 格式与内容 | 必要依据 |
|---|---|---|
| 原始输入归档 | 原XSD/OXS/图片的原字节副本，可选 | 源文件SHA，不重存JPEG冒充原件 |
| 生产画布 | CMYK TIFF，实际整布尺寸、符号、边框/刻度/校尺 | 母版、映射、格距、ICC、生产版式 |
| 整张查图 | TIFF，可选 | 查图格距与独立版式，不代替生产图 |
| 分页查图 | TIFF为厂家默认；JPG可选阅读副本 | 页窗口、全局坐标、图例、重叠计划 |
| 合并查图 | PDF，按实际纸张、原倍率或明确的阅读放大 | 当前分页与对应物理尺寸 |
| 符号表/速查卡 | TIFF/PNG/PDF按模板 | 相同映射，完整DMC对应 |
| 材料清单 | XLSX，针数模式/估算模式 | 独立计数、已配置材料规则 |
| 工程交换 | OXS全针子集，可选 | 同母版及导出能力报告 |
| 厂家包装模拟 | PNG、当前母版X针格、纯白、3:4 | 母版身份、针格与色板 |
| 商品图片 | JPG/PNG，7详情+5方图或选中目标 | SKU规格、源类型、场景及文字模板 |
| 说明 | READ_ME_EN.txt、READ_ME_CN.txt | 同一结构化数据，双语表达 |
| 厂家成品包 | ZIP | 模板白名单、实际文件、CRC和清单 |
| 可携带工程 | 拟 `.stitchpress` | 母版、资源、配置、引用完整性 |

XSD导出不纳入R1正式交付承诺；原XSD可原样归档。XSD/OXS的具体应用兼容性分别声明，不能通过换扩展名代替格式转换。

## 2 当前厂家兼容模板

每款仍为 N+6 个独立文件：1张包装模拟、1张生产TIFF、N张A4查图TIFF、1份PDF、1份XLSX、2份说明。ZIP只是容器，不另算一件。

```text
<客户号>-<EnglishName>/
  Showcase/<客户号>-Showcase-vNN.png
  Production/<客户号>-Production-300dpi-vNN.tif
  A4_TIFF_Pages/<客户号>-A4-P01-<范围>-vNN.tif
  ...
  <客户号>-A4-Reference-<N>Pages-vNN.pdf
  <客户号>-DMC-Stitch-Counts-vNN.xlsx
  READ_ME_EN.txt
  READ_ME_CN.txt
```

针格、色数或图例导致N变化时动态重算。240×320格、100×110格/页、无重叠样例有9页，合计15件；这个页容量只适用于图例能够排下的相应样例。

此兼容包不加入内部核验、原件、符号源库、工程、授权、日志或第二套缩略图。用户要求附加OXS、符号卡或商品图时使用扩展模板，明确新增文件，不再声称仍是N+6。任务清单与检查回执保留在工程记录中，不为记录哈希向兼容包强塞第N+7件。

## 3 TIFF与生产图

厂家模板要求真实CMYK四通道8位、300×300DPI、英寸分辨率单位、单页、LZW、指定ICC。通用模板可配置DPI、色彩和压缩，文件实际重新绘制；输出属性与所选工厂模板不兼容时阻止该模板发布。

大幅使用分块/分条渲染，仍遵循全局坐标，不能每块重新起算格距而产生拼缝。BigTIFF不是通用无条件替代：目标读取软件是否支持需要验证；不支持时提示降低无关像素开销或按工厂明确方式分幅，不能静默缩小物理尺寸。

生产读回检查涵盖尺寸、DPI、压缩、ICC、通道、已绣格符号像素及空白内区。外围画心框不压符号，红裁剪框不扩大整布，标题图例不占设计针格。

厂家数字字号逐项按03的v10字号表核验；生产48/50/56px及A4对应下限使用实际字体度量参与布局，不只核对配置值。

## 4 分页与PDF

布局保存：纸张物理尺寸、最终像素、原倍率/阅读放大标识、每页核心窗口与可见窗口、全局坐标、邻页、文字框、图例与校尺。

厂家A4样例为2480×3508 px、300DPI，PDF MediaBox为210×297 mm；图像按 `像素/300×72` 点嵌入并居中，不将整数像素图非等比拉满A4。检查有效内容与微小像素舍入边界的余量，不能裁切符号或校尺。设置PrintScaling=None只是建议，打印说明仍要求关闭Fit/Shrink。

PDF需要真正渲染检查，不只看源TIF或页数。核对嵌入图像的解码像素、颜色、物理矩阵和页顺序。ICC OutputIntent不等于PDF/X认证。

当前厂家每页完整列出No./Symbol/DMC，图上不显示针数；其他客户可选不同图例模板。图例溢出先重排并重算页容量，不静默隐藏最后几色。

## 5 XLSX

线号单元格为文本，针数为整数，总数为SUM公式；表头、冻结、列宽、打印区域和字体需可读。当前厂家正文字号14pt。表格可以有符号与绣线色块，但针数不能只是截图。

材料估算模式增加基础量、损耗、建议量、包装量及单位，保留规则名称/版本与口径。若多个CT需独立表/工作簿，明确每份对应SKU或材料情景，不能汇总成一列无来源米数。保存文件后重开、核对公式范围和计算结果，再检查渲染。

## 6 包装模拟与商品图

厂家模拟每个有效格与当前母版X图块一一对应，空白与扩边纯白。针格图案不拉伸；3:4通过外部白边得到。当前样例18px/格的240×320产生4320×5760，不能把这个像素密度当成印花DPI。

商品模板独立于包装模拟。三张场景、规格、原图与当前模拟对比、印花局部、洗护说明构成7张详情；5个方图槽位可切换内容。规格与货号引用当前SKU，不手填一套会过期的数字。800方图永远800×800，改变DPI元数据不改变像素数。

场景不是实物比例测量工具；没有空间尺寸标定时只声明展示用途。X模拟、点图、AI图和实绣照片的来源清楚区分。背景与字体由自有/可发行资源或客户导入提供，不分发参考APP内的资源副本。

AI生成背景和文案是可选商品素材步骤；母版主体与规格由本地合成/引用，不能让模型重画后替代精确包装模拟。模型调用失败不影响已经冻结母版的TIFF/PDF/XLSX导出。已有候选和本地模拟可复用，不因再次出包自动重新计费生成。

## 7 双语说明与文件版本

两份说明从相同结构化数据生成，包含：身份、当前设计/SKU/包版本、针格与色数、针数口径、实际格距和CT、画心/整布尺寸、留白、DPI/ICC、用途、页范围/重叠、校尺、Actual Size、材料规则、模拟来源与实物差异。

元数据中的不同产物版本可以不同：只换模拟图时，生产TIFF、PDF、Excel保持原字节，新增包版本和必要说明；不为“统一vNN”重写未变文件。文件名中的版本是展示，引用和复用以内容SHA及输入依赖为准。

## 8 导出前检查与发布

导出前展示目标清单、预计尺寸、页数、空间需求及阻塞项。磁盘估算考虑未压缩工作块和暂存空间，不能用上次ZIP大小当作本次峰值需求。

正式目录只包含通过所需核验的最终文件；中途取消/失败留在隔离工作区。整包完成后核对模板文件数、款式、版本、CRC、成员SHA、路径与是否混入内部资源。部分目标可单独完成，但不能被命名为已完成的完整厂家包。

“已生成”“数字通过”“人工检查”“待发客户”“已发客户”“试印通过”分开记录。生成、保存到云盘或客户认可外观均不自动改变其他状态。

## 9 测试输出与最终交付

客户可导出单页校尺试印，记录打印软件、实际大小设置、量得长度及布孔套准。测试页用清楚的测试名称，不替换整包最终文件。

首次工厂试印反馈关联到确切SKU、预设、产物SHA及设备配置。结果变化时形成新设备/材料规则版本，不修改设计原针格来补偿打印机缩放。
