# 产品需求

StitchPress 帮助十字绣工作室、印花工厂和材料配包人员，从文字创意、客户图片或已有工程形成可绣设计，并稳定地转换成生产、查图、配线与销售素材。AI 辅助理解、蓝图重建、局部修订和质量检查，本地生产核心保证针格、尺寸、色号和文件的一致性。

文档版本 v0.4，2026-11-11。AI为首发核心目标；设计已进入开发准备，执行顺序与状态见 [TODO](../TODO.md)，依据类型见 [00](00-来源与证据.md)。

## 1 用户与任务

| 用户 | 主要任务 | 需要得到的结果 |
|---|---|---|
| 工作室制版人员 | 导入工程、核对针格与符号、建立规格 | 可复现的作品项目与可靠交付 |
| 无现成工程的创作者/客户 | 上传图片或描述创意、采用蓝图、检查与修订针格 | 可审核、可恢复的真实母版，而非只有漂亮图片 |
| 工厂印花人员 | 选择实际格距、留边、色彩及校尺 | 能在已确认设备流程中试印的生产文件 |
| 配线与包装人员 | 核对逐色针数、套用材料规则 | 可编辑表格、明确计量单位与包装量 |
| 商家 | 改款名货号、尺寸说明、展示场景 | 与当前产品规格相符的商品图片 |
| 客户负责人 | 批量出单、返修、追溯已发版本 | 不混款、不混版本的完整包和记录 |

角色用来组织操作，不意味着首发必须做账号、权限或企业后台。第一版可以是同一台电脑上的不同工作方式。

## 2 成功场景

客户收到我们提供的作品项目，打开后看到母版、线色、符号、当前规格和最终交付记录。选择自己的工厂预设，修改留边或文字，预览完整画布和局部符号，生成需要的 TIFF、PDF、Excel 和展示图；保留本次参数，下次直接返单。

客户也能导入通过支持范围检查的 XSD/OXS，自行建立项目。另一条核心路径是上传 JPG/PNG 等图片或输入文字要求：应用形成结构化设计要求，重建或生成干净蓝图，再按指定针格和DMC目录转换，展示原图/蓝图/针格模拟对照，完成局部修订与审核后冻结母版并出包。详见 [10](10-AI制版与修订.md)。

参考后期APP主要从已有XSD出发；本产品要覆盖前端制版、可控修改和后端交付的连续过程。AI输出本身不是生产资格，冻结母版才是两条路径汇合的依据。

## 3 产品原则

1. **母版先于出图。** 针格、线色、空白和针法是设计数据，不从漂亮展示图推断生产矩阵。
2. **一个任务使用同一输入快照。** 所有文件绑定相同母版、映射与配置版本；中途改设置不影响正在导出的任务。
3. **生产配置按客户保存。** 实际格距、黑色策略、ICC、语言和配线口径可不同，不用一家工厂的偏好覆盖所有用户。
4. **显示修改影响。** 只改查图不重画生产；改映射则更新所有显示符号的产物；改针格必须重计数并作新设计版本。
5. **预览和正式文件使用相同布局计划。** 缩略图减少像素，不另写一套排版猜测正式效果。
6. **区分云端AI与本地生产。** 已有母版的业务可离线；云端AI阶段需要连接和独立费用额度。AI失败不能阻断已有工程的打开、修改配置与导出。
7. **双端同业务语义。** Windows/macOS 共用项目文件、数值规则和验收样本；不承诺两个平台所有编码文件字节完全相同。
8. **AI提出候选，变更有范围。** 模型不直接覆盖冻结母版。受控局部改动以明确区域和精确变更清单应用，区域外保持原针格及线色；审核与数值检查不能被模型一句“通过”替代。

## 4 完整产品范围

参考 APP 的功能逐项进入 [02](02-参考功能对照.md)。R1 完整首发目标包括：

- 原生作品项目、受限全针 XSD/OXS 导入、对照原图、身份与预设管理。
- CT/实际格距/画心宽度换算、四边留白、DPI、ICC、印花和查图分别配置。
- 符号库导入、版本化编辑、自动分配、指定与交换、DMC 排序、符号表与速查卡。
- 画布、整张查图、分页、页码坐标、图例、标题页脚、字号、颜色与占位符。
- 准确逐色针数、可选材料规则、可编辑 XLSX。
- 母版 X 针格模拟、家居场景与画框、局部展示、7 张详情图和 5 张方图。
- 单项或完整导出、批量队列、取消重试、检查点、核验记录、作品可携带包与交付 ZIP。
- 离线授权的导入/状态/到期/续期入口；具体试用期限和计费规则待定。
- Windows 与 macOS 应用构建、干净环境安装、中文路径、无系统 Python 使用、跨端项目交换。
- AI需求理解、原图分类、文字创作/来图蓝图生成、候选采用、DMC受限针格转换、浅色与负空间检查、局部指令修订、三方对照、审核冻结及模型接入/费用记录。对应 A01–A12，详见 [02](02-参考功能对照.md) 与 [10](10-AI制版与修订.md)。

功能表中的 R0 是内部开发顺序。R0 做完不等于已交付覆盖参考主要功能的 R1。

## 5 首发边界

| 项目 | R1 行为 |
|---|---|
| 针法 | 生产链仅接受明确验证的全十字；遇未支持针法停止导出并说明位置/数量，不静默降级 |
| XSD | 目标支持经测试的 Pattern Maker v4 全针子集；保留原文件及导入报告，不宣称所有 XSD 通用 |
| OXS | 全针子集，单位、坐标与线色索引往返核对；对 Saga 等具体应用的兼容名称须实机验证 |
| 普通图片/文字 | 进入AI辅助制版，也可只作对照；转换、检查、审核冻结之前不开放正式生产导出 |
| 图案编辑 | R1包含受控区域修订、参数化减色候选、浅色补针候选及精确针格变更；不提供任意脚本执行或一键填满所有空洞 |
| 钻石画模拟 | 可作为明确标识的可选展示样式；默认十字绣 X 模拟，不改变材料或针法统计 |
| 云盘和消息 | 不继承原项目的私人网盘授权；首发本地交付，后续由用户配置连接 |
| 实物结论 | 区分数字核验、人工外观检查、设备试印和洗水反馈 |
| 商业化 | 可以预留授权能力，不以完整支付/商城/企业账号系统阻塞印花工作流 |
| AI接入 | 支持按能力配置真实模型服务，首发至少验证一个可完成全流程的组合；独立APP不继承本聊天的工具或账号 |
| 自动化 | 阶段可连续运行，采用蓝图与冻结母版是默认内容检查点；重试有次数/费用上限，不做无限自动重画 |

## 6 客户预设与通用产品的关系

当前厂家方案作为“EVERFLOW 合作厂家 14CT v10”导入模板：0.181 cm、四边 30 格、300DPI、指定 ICC、66 符号、四色黑、生产无内部网格、原倍率 A4、英文印刷标签与双语说明。

这些值在该预设内有明确来源。客户另建规格可以修改；修改后生成新规格版本，保留原有预设快照。不能仅改界面布号就悄悄改变实际格距，也不能修改模板后让历史订单自动重新计算。

## 7 产品验收的成果

验收不是“所有按钮能点”：需提供可打开的双端应用、可交换的作品项目、已有工程及客户来图两条流程的示例交付包、逐格/尺寸/表格检查结果、AI阶段的原图与候选证据及已声明的格式兼容范围。详细规则见 [08](08-验收与测试样例.md)。

首轮业务评估关注：客户能否独立完成一款导出、返单能否恢复原配置、只改一项是否只重做必要文件、两端是否得到相同针数和尺寸。耗时和内存先建立可重复测量基线，再设性能目标，不在设计阶段编造秒数。
