# dev14 符号编号与小尺寸打印修复

## 原因与改动

用户的客户152符号库中，原始符号是20×20像素。Qt图标默认不会放大原始小图，原图库又叠加了单元格内边距，导致编号实际可用宽度不足，同一行的061完整而062等变成省略号。

图库改为96×96逻辑像素单元格，移除单元格多余内边距，禁止编号省略并允许较长标识换行。显示缓存提供最长80像素的清晰缩略图，支持40逻辑像素的高分屏展示；不改变客户符号源字节、印刷颜色或绑定。

13×18格郁金香使用理论14CT时，旧校尺把循环小数完整输出为二十多位，触发文字越界。生产与查图校尺统一最多显示4位小数（如 `13 cells = 2.3586 cm`），去除末尾零；针格坐标、布面尺寸和实际校尺线长仍沿用完整Decimal精度，字号不缩小。

扩大到600DPI回归时另发现生产外框的向内描边会覆盖最右和最下针格各一个像素。现按线宽把外框完整放在针格外；300DPI原坐标不变。
