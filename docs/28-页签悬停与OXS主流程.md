# dev13 页签悬停与 OXS 主流程

## 页签修复

用户反馈为“预设已选中时，鼠标移到标题与页脚出现大块悬停底色与黑色底线”。原样式使用透明页签背景，独立 QTabBar 同时保留原生底座绘制。

改为显式关闭底座、固定不透明主题底色，统一中性细线与绿色选中标记。悬停只调整文字颜色，不绘制额外矩形；页签字重保持一致，避免切换时宽度跳动。日夜主题各反复移动鼠标，检查未选中页签的背景像素、底部尾区及几何尺寸，保留当前选中“预设”不变。Mac实际窗口检查了原生主/子页签、日夜主题与窗口缩放。

## OXS 接入范围

底层已有 OXS 全针解析，本次把它接入一期主流程：

- 作品页“导入图纸…”及文件菜单同时提供 XSD / OXS；不需要进入实验工具。
- 自动识别扩展名，复用同一母版、符号映射、印花与查图输出。空白与白针语义保持区分。
- 首次导入可读取 `charttitle` 为作品名、以文件名作为建议货号，保留前导零。已有正式货号仍保持原值。
- 自包含作品、设置 JSON 连同原始 OXS 字节留底；同名对应图发现也支持 OXS。
- “原始图纸”输出保持输入格式，OXS仍导出`.oxs`且字节/哈希一致，不冒充XSD。
- 当前母版已编辑时，不能把旧 OXS 原稿当作当前版本输出；与原XSD相同地阻止错版。

支持明确声明的 **OXS 1.0 全针图纸**。含回针、半针、混线或未知针法的文件继续明确拒绝，保持当前作品，不静默丢针。本次没有加入新针法语义。
