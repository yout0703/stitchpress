# StitchPress 七天离线试用版

解压完整文件夹后，双击 `StitchPress.exe` 打开软件。请保留同目录的配套文件。

1. 首次打开，点击“导出本机机器码”，把生成的 JSON 文件交给软件发行方。
2. 收到 `.spl-license` 授权文件后，点击“导入试用授权”，再点击“进入软件”。
3. 授权绑定当前电脑，**从发行方签发时间起连续七天（168小时）有效**；安装、下载或导出机器码不会开始试用。授权界面显示准确到期时间。
4. 使用期间无需联网。菜单“试用授权”可查看期限或导入新授权。

到期后，编辑、制版、预览和导出等业务功能锁定。已保存工程与已导出成品继续保留；正在编辑的内容会尝试保存为独立恢复草稿。请在到期前主动保存，恢复副本保存失败时请保留窗口并联系发行方。

换电脑、系统时间异常或到期后需要继续使用，请联系发行方处理。升级、重新安装、重新导入同一授权文件不会改变其原到期时间。不要通过修改系统时间延长试用。

本包是试用候选版，正式生产前请核对尺寸、符号、配线参数，并先做实际试印。
