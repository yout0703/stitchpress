```bash
uv sync --locked --all-groups
uv run stitchpress-desktop
# 检查
uv run --all-groups ruff check src tests tools
QT_QPA_PLATFORM=offscreen uv run --all-groups pytest -q
# 在目标系统本机构建
uv run --all-groups python tools/build_desktop.py
```

Mac本机通过PyInstaller构建，试用应用生成于 `dist/macos/StitchPress.app`。开发样本和检查留底在 `reports/local/`；安装包及客户资源不推送到Git。

主界面以「作品 → 印花与图纸 → 符号与配线 → 商品图片 → 检查与导出」五个工作区组织。全局文件操作集中到文件菜单；AI、旧针格编辑台与专用交付移入扩展（实验）。文字归图纸、配线归符号，实际预览内嵌，导出操作固定；左下角切换白天/夜间。完整归属与交互约定见[信息架构与现代工作台](docs/17-信息架构与现代工作台.md)。dev5进一步优化作品概览、双栏表单、编辑状态和预览有效性，见[菜单交互复查与视觉优化](docs/18-菜单交互复查与视觉优化.md)。

使用环境补充（2026-11-11）：客户目前只有Windows；我们主要在macOS开发调试。因此以Windows为客户交付与体验验收主平台，macOS版本用于日常开发、调试和跨端核对，保留此前两个平台可运行版本的目标。客户尚未提出macOS商业使用需求。

## 已明确的方向

- 一期从已有XSD及对应图片开始；二期扩展文字创作、来图重建和针格转换，图片不能直接作为生产矩阵。
- 2026-11-11用户最新决定：一期首先复刻参考主要功能，二期再加入AI和我们的优化/交付；此安排替代此前AI列R1前置的顺序。已有AI、本地交付和双主题代码保留。
- 设计母版、产品规格、符号映射和导出任务分别管理，所有产物追溯同一输入快照。
- 覆盖参考 APP 的主要能力，包括符号库、配线、家居模板、电商 7+5 图；首版免费，不启用授权限制，离线授权留作后续可选；阶段实施不等于删除完整目标。
- 参考全套TIFF/JPG/BMP/XLSX/XSD/JSON是一期明确目标；PDF/OXS、白底X、厂家v10/N+6/双语ZIP等保留为二期增补，准确计数及安全存储基础两期共用。
- 当前客户的 0.181 cm、66 符号、四色黑等是特定预设，不是对所有客户强制的全局标准。
- 本地优先；已有母版的打开、配置、预览及已授权导出可离线。云端 AI 阶段需要所选服务连接，生成结果保存后可继续本地制版与交付；云同步不作为首发依赖。
