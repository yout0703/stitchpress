# 绣印工坊 StitchPress

集 AI 辅助创作、来图制版、印花交付与商品展示于一体的十字绣桌面工作台。

本项目已进入0.1.0.dev1本地实现阶段。设计覆盖“十字绣后期试用版”的主要功能，并把AI创作、来图重建与可绣母版审核纳入核心范围。Windows和macOS共用业务核心与作品格式，分别构建和验收。

已实现Mac桌面小样和本地制包核心；完整R1仍在开发，Windows、真实AI与工厂验收尚未完成。实际边界见[本地实现与技术验证](docs/12-本地实现与技术验证.md)。

```bash
uv sync --all-groups
uv run stitchpress-desktop
# 检查
uv run ruff check src tests tools
QT_QPA_PLATFORM=offscreen uv run pytest -q
# 在目标系统本机构建
uv run --group build python tools/build_desktop.py
```

Mac本机通过PyInstaller构建，试用应用生成于 `dist/macos/StitchPress.app`。开发样本和检查留底在 `reports/local/`；安装包及客户资源不推送到Git。

界面已采用专业制版台布局：左侧常驻线色与符号，中间画布，底部局部修订，规格与转换按需展开。右上角可切换白天/夜间主题并记住本机选择；主题不修改母版或导出颜色。设计及验证范围见[桌面界面与双主题](docs/13-桌面界面与双主题.md)和[视觉验收](design-qa.md)。

使用环境补充（2026-11-11）：客户目前只有Windows；我们主要在macOS开发调试。因此以Windows为客户交付与体验验收主平台，macOS版本用于日常开发、调试和跨端核对，保留此前两个平台可运行版本的目标。客户尚未提出macOS商业使用需求。

## 已明确的方向

- 同时支持文字创作、客户来图和已有可绣工程三类入口；图片先形成审核后的母版，不能直接作为针格交付。
- AI 能力进入 R1 首发核心目标，不再只是 R2 候选。AI 负责理解、蓝图和修订建议，本地程序负责针格、精确计算和文件导出，用户保留采用和冻结控制。
- 设计母版、产品规格、符号映射和导出任务分别管理，所有产物追溯同一输入快照。
- 覆盖参考 APP 的主要能力，包括符号库、配线、家居模板、电商 7+5 图；首版免费，不启用授权限制，离线授权留作后续可选；阶段实施不等于删除完整目标。
- 保留现有交付经验，包括原倍率 PDF、白底 X 针格模拟、精确逐色针数和客户专用印花预设。
- 当前客户的 0.181 cm、66 符号、四色黑等是特定预设，不是对所有客户强制的全局标准。
- 本地优先；已有母版的打开、配置、预览及已授权导出可离线。云端 AI 阶段需要所选服务连接，生成结果保存后可继续本地制版与交付；云同步不作为首发依赖。

## 当前AI配置

默认DeepSeek Flash，模型ID `deepseek-flash`，支持文字/图片需求分析设置。用户稍后在软件中配置API密钥，密钥只存本机系统安全存储；保存配置不调用模型。图像生成/编辑单独配置，供应商及适配协议待提供，当前不可据此生成图片。

客户资源在本机`.local/`通过导入使用，不随Git或通用安装包分发；示例仅使用自有测试图。当前未加入云上传、客户通知或自动计费调用。
