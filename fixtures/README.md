# 开发夹具

这里只包含自有或独立构造的工程数据，不包含客户图稿、客户符号或参考EXE资源。

- `s01.oxs`：人工逐坐标写出的3×2非对称样例；预期矩阵、针数在测试中独立声明。
- `s01-independent.xsd`：复用同一开发者StitchForge项目的独立二进制夹具，4×3、非零密钥，非本项目导出器生成；来源函数`tests/test_xsd.py::native_sample`。预期线号310/B5200，各3针。
- `manifest.json`：S01–S20覆盖入口。`specified`只表示样本契约存在，不表示对应完整业务已通过。
