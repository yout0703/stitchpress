StitchPress 0.1.0.dev6 · 一期参考流程

首版免费。一期以已有全针 XSD 开始；不调用 AI。原有 AI 和专用交付保留于“扩展（实验）”，二期暂不继续开发。

1. 作品：导入全针 XSD，查看针格、针数、空白及原件 SHA。遇到半针、回针、混线等不支持内容会停止。采用文件名作为货号建议，再人工核对前导零；“发现同名对应图”只列候选，采用后仍须确认对应关系。
2. “文件”菜单打开 / 保存 .stitchpress 工程可保留历史。另存作品设置 JSON 时，会建立相对资源目录；二者一起移动。缺失资源可重新定位，SHA 不同不会替换原件。输出父目录属于本机设置，每次建立新版本，不覆盖旧输出。
3. 印花与图纸：生产按实际 X/Y 格距、四边留白和生产 DPI 绘制。CT 可计算理论格距，目标画心宽度保持原比例；横纵等效CT单独显示，不更改名义布号。查图 DPI、每格 mm、页边距、纸张方向和重叠独立；查图变化不会修改生产针格与尺寸。留空使用基础参数；每格 mm 填写后采用该直接尺度。预设支持另存、应用、移出列表和恢复默认。
4. 印花与图纸 → 标题与页脚：画布、查图、符号表的顶底栏可分别显示、设字体、字号、CMYK、对齐及 mm 偏移。模板支持字段预览；缺字或越界会停止。留空沿用基础文字，关闭“显示此栏”清除基础文字。在“符号与配线 → 配线规则”中，每 CT 配置已确认的每米针数及来源，米数逐色向上取整；各 CT 分别生成带符号、色块和作品信息页的 Excel。示例系数不是客户材料规则。
5. 符号与配线：左侧选符号、右侧选线色，指定被占符号会整体交换；两色都记录手动保护。自动匹配先保留手动项，其余按用针数优先，以平均着墨色接近匹配。可以明确取消保留手动项。管理符号库支持库名称/改名；库编辑与文件夹导入建立新库，旧库和原图保留。整数 ID、0.1 和前导零文本不混同；容量不足、重复图块和坏 ICC 会停止。
6. 检查与导出 → 实际预览：选择生产、整张 / 分页查图、符号表、速查卡、点图或电商目标及页码。切换目标隐藏旧图，查看商品图会直接生成当前场景的预览。刷新使用实际渲染，支持缩放 / 100% 像素。过大生产图显示有内存上限的完整缩略概览，并标记原始与预览尺寸；概览100%指预览像素；完整生产文件使用分条生成。参数未应用时禁止将旧配置当作新预览，迟到结果不覆盖新作品。
7. 商品图片：原图 / 钻石点图 / X 模拟切换，三场景各自保存；缩略选择器展示横 / 竖 / 方示意。可改框边、卡纸、位置、局部中心、文字及背景。7 张详情默认 1200×1600，可自定义；5 张方图始终 800×800，内容各自替换。详情与方图 DPI 分开。可导出全部、分组或单张 JPG；来源对比必须有对应图，内置场景是示意插画。
8. 参考全套：按勾选生成原 XSD、对应 JPG、CMYK 生产 / 整张查图 / 符号表 / 速查卡 TIFF、各 CT XLSX、点图 BMP、分页 JPG、可选电商 JPG、设置 JSON 与资源及核验 JSON。JPG 有损，记录编码质量和误差，不宣称无损。所选输入缺失会明确停止，不以其他格式冒充。
9. 默认草稿带 DRAFT。正式输出需要客户符号库和 CMYK ICC、对应图人工确认，以及当前参数核对登记；不要求二期专用交付冻结。生产 BigTIFF 必须确认目标读取软件兼容；仍受本地像素限值保护，不承诺超大文件支持。文件在后台分阶段生成，取消不发布半成品，成功后可打开目录。
10. 每页“应用更改”将表单应用到草稿，“恢复本页”放弃该页未应用修改；顶部保存将已应用草稿保存到作品。有修改时应用/恢复按钮才启用；恢复保留当前页签。页面有未应用修改时会提示，避免静默丢参数。保存历史和恢复副本保留原有机制；尚未应用的页面编辑不是已保存的作品参数。

数字核验、人工外观、Windows 目标软件与工厂试印 / 洗水分别记录。Mac 和小样通过不能代替其余验收；当前 Windows x64、客户软件、真实生产仍待配合。

历史扩展能力（不属于当前一期新增范围）：

- “蓝图候选”先比较真实文件，再勾选确认采用；原件、规范图和旧版都保留。供应商信息仅为人工来源声明，不代表软件已调用AI。
- “只转换当前选区”只改选区针格；“同画幅局部编辑”要求你明确确认图片已对齐，软件只取选区像素，外区保留原版。保护区和负空间不能被改写。
- 重转后可在“针格候选比较”查看旧修订可迁移/冲突/已包含项。默认不迁移；勾选后先生成新候选，再比较采用。大列表支持分页，跨页保留勾选。
- 蒙版多边形：左键逐点、右键或双击完成、Esc取消。管理窗口可逐条移除；按格中心规则填充，不平滑、不自动填洞。源图或网格改变需要重新核对标注。
- “制版流程与检查点”可选择入口、暂停和恢复；继续只做下一本地步骤，不调用模型或自动审核。换设备需明确新建本机接续流程。
- 冻结绑定源图/设计要求/蒙版/源ICC。即使针格相同，更换这些内容也要重新审核。整包完成只认当前所有生产配置，旧货号/旧尺寸输出不算当前完成。
- 当前作品格式schema 2。打开旧schema 1工程时，保存会要求另存升级副本，不覆盖原文件。旧程序不能打开新格式；请保留原件。升级保留资源，旧审核需复核来源。

工作区快捷键：Windows Ctrl+1–5 / macOS Command+1–5；打开/保存使用系统标准快捷键。
